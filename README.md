# Likith Gowda K — Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Sections
- Home
- About
- Education
- Skills
- Certifications
- Contact

## Run locally
Simply double-click `index.html`, or open the folder with VS Code and use any local server extension.

## Customize
- Edit text in `index.html`
- Change colors/layout in `style.css`
- Update interactions in `script.js`
- Add certificate files/links in the Certifications section

## Certificate source files
Original certificate PDFs are included in the `certificates/` folder and linked from the Certifications section.
